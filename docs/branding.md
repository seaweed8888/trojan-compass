# Trojan Compass logo

The shared logo uses a gold compass, light-gray TROJAN text, and gold COMPASS text on cardinal red. It was generated and edited with the built-in image-generation tool, then resized without changing the artwork.

- Master: `web/public/images/trojan-compass.png` (1024 × 1024, opaque PNG).
- Web: header logo, 64px favicon and 180px Apple touch icon.
- Campus: matching assets in `demos/usc-map/assets`, copied into the iOS embedded site by the mobile build.
- Native iOS: `mobile/TrojanCompass/Assets.xcassets/AppIcon.appiconset`, selected in both Xcode build configurations. Rebuild and reinstall the app to update its home-screen icon.

The native catalog uses Apple's [single high-resolution app icon](https://developer.apple.com/documentation/xcode/configuring-your-app-icon) workflow. Native compilation and home-screen rendering require Xcode on macOS.
